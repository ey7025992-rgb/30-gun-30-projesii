# To-Do List (CLI)

Terminalden çalışan, görevleri ekleyip/silip/tamamlayabildiğin ve JSON dosyasına kaydeden bir görev yöneticisi.

## Özellikler
- Görev ekleme, listeleme, tamamlandı işaretleme, silme
- Görevler `gorevler.json` dosyasında saklanır — program kapatılsa bile kaybolmaz

## Çalıştırmak için
```bash
python main.py
```
