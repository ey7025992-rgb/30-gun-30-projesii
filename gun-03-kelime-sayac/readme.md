# Kelime Sayaç

Bir metin dosyasındaki satır, kelime ve karakter sayısını hesaplayan basit bir script.

## Özellikler
- Kullanıcının girdiği dosya adına göre analiz yapar
- Satır, kelime ve karakter sayısını ayrı ayrı gösterir

## Çalıştırmak için
```bash
python main.py
```
Sonra dosya adını gir (örn. `ornek.txt`).

## Örnek çıktı
```
Analiz edilecek dosyanın adını girin: ornek.txt
📄 Dosya: ornek.txt
Satır sayısı: 5
Kelime sayısı: 42
Karakter sayısı: 312
```
