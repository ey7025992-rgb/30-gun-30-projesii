# Basit Hesap Makinesi

Terminalden çalışan, kullanıcının istediği kadar işlem yapabildiği basit bir hesap makinesi.

## Özellikler
- Toplama, çıkarma, çarpma, bölme işlemleri
- Sıfıra bölme ve geçersiz işlem kontrolü
- `q` yazana kadar sürekli yeni işlem yapabilme

## Çalıştırmak için
```bash
python main.py
```

## Örnek kullanım
```
Birinci sayı (çıkmak için q): 10
İşlem seç (+, -, *, /): +
İkinci sayı: 5
Sonuç: 15.0
```
