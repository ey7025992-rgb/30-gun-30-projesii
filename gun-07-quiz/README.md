# Python Bilgi Yarışması (Quiz)

Terminalden çalışan, Python temel bilgilerini test eden çoktan seçmeli bir quiz uygulaması.

## Özellikler
- 10 soruluk bir havuzdan her seferinde rastgele 5 soru seçilir
- Sorular her çalıştırmada farklı sırada ve farklı kombinasyonda gelir
- Yanlış cevaplarda doğru cevap gösterilir
- Sonunda doğru sayısı ve başarı yüzdesi hesaplanır

## Çalıştırmak için
```bash
python main.py
```

## Örnek çıktı
```
🧠 Python Bilgi Yarışması
Toplam 5 soru var. Başlayalım!

Soru 1: Python'da bir listeye eleman eklemek için hangi metod kullanılır?
  a) add()
  b) append()
  c) push()
  d) insert_end()
Cevabın (a/b/c/d): b
✅ Doğru!

...

--- Sonuç ---
5 sorudan 4 tanesini doğru bildin.
Başarı oranı: %80
```
